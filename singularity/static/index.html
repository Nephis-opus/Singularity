Claude Desktop Setup & Third-Party Inference Guide

Desktop App

Follow these steps to enable Developer Mode in the official Claude Desktop application and configure Third-Party Inference through your local Singularity bridge.

1
Install & Launch Claude Desktop

Download and install the official Claude Desktop app for macOS or Windows. Launch the application, but stay on the sign-in screen (do not log in with an Anthropic account):

https://claude.ai/download
Windows Tip: If the top menu is inaccessible while signed out, click the email input, press Tab, then press Enter.
2
Start the Singularity Bridge

Click the Start Bridge button at the top of this panel, or run from your Singularity repo folder:

./singular claudecode start

Check bridge health and verify it is listening:

curl -s http://127.0.0.1:6045/health
3
Enable Developer Mode

In Claude Desktop's top application menu bar, navigate to:

Top Menu Help > Troubleshooting > Enable Developer Mode (or Help > Enable Developer Mode)

Claude Desktop will prompt to restart automatically. Click to restart. Once reopened, a new Developer menu item will appear in the top menu bar.

4
Configure Third-Party Inference

Click top menu: Developer > Configure Third-Party Inference... and enter these parameters:

Provider Gateway (Universal Gateway)
Credential Static API key
Base URL http://127.0.0.1:6045 (do not append /v1)
API Key Insom-Singularity (or your custom Gateway key)
Scheme Bearer

Quick copy Gateway Base URL:

http://127.0.0.1:6045
5
Turn Off Model Discovery & Add Models

In the same configuration dialog, scroll down past the Connection parameters:

Discovery Turn OFF "Model discovery" (disable auto-discovery to unlock manual model definitions)

Under Model list, click to add your models with these exact fields:

Model ID claude-opus-4-6 (or any model ID from the table below)
Display Name Gemini 4 Argon (custom name shown in Claude Desktop picker)
1M Context Turn ON "Offer 1m context variant"
Only 1M Turn ON "Only show 1mil variant" (cleanly displays the 1M variant without duplicates)
Tier Alias Set to opus (or sonnet / haiku depending on model class)

Repeat this step for whatever models you need (e.g. claude-opus-4-7 for Kimi K3, claude-opus-4-8 for Qwen 3.8 Max, etc.).

6
Save Changes & Restart Claude Desktop

Click Apply locally (or Save changes) at the bottom of the dialog, then quit and restart Claude Desktop.

Claude Desktop will re-initialize in third-party inference mode (Cowork on 3P). You can now bypass the sign-in screen, pick your configured 1M models directly from the model selector, and enjoy unmetered frontier intelligence through Singularity!
